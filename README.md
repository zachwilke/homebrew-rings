# Homebrew tap for [rings](https://github.com/zachwilke/rings)

DaisyDisk-style disk usage TUI. Prebuilt binaries from GitHub Releases (macOS Intel/Apple Silicon, Linux x86_64/arm64 musl).

```bash
brew install zachwilke/rings/rings
```

That taps this repo (`homebrew-rings`) and installs the formula. Upgrade with `brew upgrade rings`.
